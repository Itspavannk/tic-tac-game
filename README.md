# Tic Tac Toe 🎮

A modern, next-generation Tic Tac Toe game built using  
HTML, CSS, and JavaScript with a clean UI and smooth gameplay.

## Features
- Interactive two-player mode
- Neon-style X & O
- Glassmorphism UI
- Responsive design
- Reset and New Game options
